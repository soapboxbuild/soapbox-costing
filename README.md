# Soapbox Costing

Construction cost intelligence for building decarbonization.

Soapbox Costing provides equipment cost estimates, economic analysis, and service-capacity planning for energy efficiency and renewable energy measures. Estimates cover:

- **CapEx** (capital cost ranges: low, base, high estimates)
- **OpEx delta** (operational cost impacts)
- **Distributed energy economics** (PV, storage, HVAC efficiency)
- **Electrical service capacity** (panel upgrades, infrastructure requirements)

All costs are surfaced with source citations for transparency and traceability.

## Data Sources & Licensing

Built on publicly available cost databases: EIA, URDB, Scout, DEER, TRMs, and REopt. For detailed methodology and data source citations, see the [design specification](https://github.com/soapboxbuild/soapbox-agent/blob/main/docs/superpowers/specs/2026-07-10-soapbox-costing-design.md) in soapbox-agent.

RSMeans data is **not redistributable** and is integrated via licensed provider APIs where applicable.

## Reference Library

The costing reference library grows over time as regional data is added and methodologies are refined. Current coverage focuses on US residential and small commercial buildings.
